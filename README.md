An entry for make.fun's [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) bounty: a two-part micro-confession — a To: line naming who it was meant for, and the unsent message itself, one line written exactly as it was typed, with no explanation after it. The reason it stayed in drafts is felt in the words, not stated.

`main.py` (Python 3, stdlib only) writes the confession to `/output/entry.txt`, deterministically, via a temp file plus rename with mode 644.
